## 🔍 Project Overview
This module documents the practical implementation of **Footprinting and Reconnaissance Attacks using the Google Hacking Database (GHDB)** as part of the Networkwalks Cybersecurity Internship. The primary objective is to leverage advanced Google search operators (Google Dorks) to locate exposed public assets, live security cameras, and open directories containing educational resources without actively scanning or interacting with the target infrastructure.

---

## 🎯 Background & Objective
Reconnaissance is the foundational phase of any comprehensive security assessment. By utilizing Google's extensive indexing capabilities through GHDB queries, security professionals can identify accidental information disclosures—such as open camera feeds and public file repositories—before malicious actors exploit them[cite: 6, 14].

### Core Tasks Completed:
1. **Task 1:** Discovered and cataloged 10 live, vulnerable security camera links exposed on the internet using specialized GHDB dorks[cite: 3, 6].
2. **Task 2:** Identified 10 open directory listings containing downloadable mathematics textbooks in PDF format[cite: 3, 6].
